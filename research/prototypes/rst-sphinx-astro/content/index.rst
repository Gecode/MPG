Modeling and Programming with Gecode
=====================================

.. mpg-part:: Modeling
   :authors: Christian Schulte, Guido Tack, Mikael Z. Lagerkvist
   :letter: M

   This part demonstrates the classical MPG opening-page grammar while using
   canonical reStructuredText as the source. It contains native chapters,
   numbered programs, mathematical notation, figures, tables, and tips.

   **Basic material.** Start with the first model, then use the harder pages to
   check that dense technical content still fits the classical book design.
