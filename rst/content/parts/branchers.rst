Programming branchers
=====================

.. mpg-part:: Programming branchers
   :letter: B
   :authors: Christian Schulte

   .. mpg-part-blurb-start

   This part presents how to program branchers as implementations of
   branchings.

   :doc:`../branchers/started` shows how to implement simple branchers. More
   advanced topics are discussed in :doc:`../branchers/advanced`.

   How to implement a whole array of variable-value branchings (a need that
   typically arises when implementing new variables) is discussed in
   :ref:`chap:v:branch` of :ref:`part:b`.

   .. mpg-part-blurb-end
