Programming search engines
==========================

.. mpg-part:: Programming search engines
   :letter: S
   :authors: Christian Schulte

   .. mpg-part-blurb-start

   This part shows how to program search engines in Gecode.

   :doc:`../search-engines/started` presents how to implement simple search
   engines, where the focus is on understanding the basic operations available
   on spaces to implement search engines. :doc:`../search-engines/recomputation`
   explains recomputation as the most essential technique for efficient search
   in Gecode. :doc:`../search-engines/engine` puts all techniques for search and
   recomputation from :ref:`chap:s:started` and :ref:`chap:s:re` together and
   presents a realistic search engine.

   .. mpg-part-blurb-end
