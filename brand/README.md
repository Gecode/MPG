# brand

`mpg-mark.svg` is the MPG mark: an open book drawn with the cards and
colors of the Gecode logo. The T3 Code project sidebar uses it.

`mpg-social.png` is the GitHub social preview image (1280 × 640).

`mpg-banner-light.png` and `mpg-banner-dark.png` head the repository
README, one for each GitHub color scheme.

The mark should also become the favicon of the MPG web edition, but only
as part of a future redesign of the site. Until then the site keeps its
current favicon.
